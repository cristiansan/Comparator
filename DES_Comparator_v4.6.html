📖 How to Use DES Comparator

1 Download from AIR

Click the (Link) to download the Products file from AIR. You must be logged in to AIR first. This downloads an Excel file with all product data.

2 Process RAW File

Click (Link) to select the downloaded RAW file. This filters the columns to keep only relevant data and automatically loads it as the Current File. A processed file will be downloaded with a date-based name (e.g., feb3.xlsx).

3 Previous File

Select the previous week's processed file to compare against. This is the baseline for detecting changes.

4 Current File

Select the current file (automatically loaded if you used step 2). This is compared against the Previous File to find changes.

5 Compare Files

Click to run the comparison. If no files are loaded, you can select a folder and the app will automatically load the oldest and newest files based on their names (e.g., jan5.xlsx, feb3.xlsx).

🔍 Filters

Product ID: Filter by one or more Product IDs (comma-separated).
EID: Search by person's name or surname.
Role: Filter by specific role.
Type: Filter by change type (New Entry, Added, Removed, etc.).
Cell: Filter by Cell (Pioneers, Pathfinders, Propel).

✉️ Sending Emails (Auto Send)

Use the checkboxes on the left to select emails, then click Auto Send to send them automatically via Outlook. Use the ✉️ button in each row to preview and send a single email. Emails are sent directly without manual clicks.

🖥️ Server Setup (Required for Auto Send)

The Auto Send feature requires a local Python server. Setup steps:

1. Install Python (if not installed):
Download from python.org and check "Add Python to PATH" during installation.

2. Install libraries (one time):
pip install flask flask-cors pywin32
If pip not found, try: python -m pip install flask flask-cors pywin32

3. Start the server (before using Auto Send):
python server.py

4. Keep the terminal open while using the comparator.
5. Server status shows as "● Server OK" when running.

📋 Email Log

The Log button tracks all emails you've opened. Use Export Log to download a CSV file with your email history. Share this file with teammates and use Import Log to merge their logs with yours. Use View Log to see recent emails sent.
